## 설계 근거는 Notion에

이 레포의 문서는 **무엇을 만드는지**를 다룹니다. **왜 그렇게 설계했는지**는 Notion에 있습니다.

| 번호 | 제목 | 언제 보는가 |
|---|---|---|
| 1 | 문제 정의와 시장 검증 | 왜 이 문제를 푸는가 |
| 2 | 왜 블록체인인가 | 왜 온체인이어야 하는가 |
| 3 | 사용자 경험과 원장 구조 | 3단 원장, 사용자 화면 |
| 4 | 시스템 및 스마트 컨트랙트 설계 | 컨트랙트 구조, 상태 전이 |
| 5 | 데이터 흐름과 저장 구조 | 스냅샷 규칙, 라벨 매핑 |
| 6 | 유동성·위험·수익 구조 | 담보율 · 워터폴 · 한도의 근거 |
| 7 | 유휴자금 운용 설계 | 외부 운용, 서킷 브레이커 |
| 8 | MVP 범위와 실행 계획 | 범위 경계 |
| 9 | 데모 화면과 시나리오 | 시나리오 상세, 시점별 수치 |
| 10 | 결정 기록과 미해결 과제 | 왜 그렇게 정했는지 |
