# `shared/` — 세 사람 사이의 계약

**여기 있는 파일은 혼자 고치지 마세요.**

이 폴더는 프론트엔드 · 컨트랙트 · 어댑터가 서로를 믿고 개발할 수 있게 해주는 인터페이스입니다. 여기가 어긋나면 세 사람이 동시에 깨집니다.

## 소유와 사용

| 경로 | 소유 | 사용 |
|---|---|---|
| `abi/` | **B(민서)** | C(민재) (서명 타입 import), A(서진) (이벤트 이름) |
| `types/` | **A(서진)** | B(민서), C(민재) (출력 형태) |
| `copy.ts` | **A(서진)** | — |
| `snapshots/sample/` | **A(서진)** | B(민서), C(민재) (목표 형태) |
| `snapshots/run-*/` | **B(민서)** (생성) | A(서진) |
| `labels/` | **C(민재)** | A(서진) |

## 변경 절차

```
1. 소유자가 초안을 만든다
2. shared/ 에 올리고 PR을 연다       제목: [shared] ...
3. 팀에 한 줄 알린다                 "올렸습니다. 내일 저녁까지 이견 없으면 확정합니다"
4. 기한 안에 이의 없으면 확정
5. develop에 머지하고 "확정" 알림
```

**확정 후에 바꿔야 한다면** 같은 절차를 다시 밟되, 그 계약에 의존하는 사람에게 **직접 알립니다.** PR만 올리고 끝내면 상대는 모르고 옛 버전으로 계속 만듭니다.

`shared/` 변경 PR은 **소유자 승인이 필수**입니다.

## 특히 조심할 것

**C(민재)는 EIP-712 구조체를 직접 작성하지 않습니다.** B(민서)가 `abi/`에 내보낸 타입을 `import`해서 씁니다. 양쪽에서 각자 손으로 적으면 한 글자씩 어긋나고, 서명 검증이 전부 실패합니다.

**포지션 상태값 철자**는 컨트랙트 enum · DB 컬럼 · 스냅샷 필드 · 화면 라벨이 전부 같아야 합니다. `types/snapshot.ts`의 `PositionState`가 기준입니다.

자세한 내용은 `PRD.md` 10장을 보세요.
